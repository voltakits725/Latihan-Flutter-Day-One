# Buah ANjay 🍏

Tugas Matkul Aplikasi Mobile.
Aplikasi antarmuka buah sederhana untuk mengimplementasikan dasar-dasar widget di Flutter.

## Materi yang Diterapkan

* **Custom Widget:** Memisahkan UI menjadi komponen `StatelessWidget` tersendiri agar kode tidak berantakan (*Clean Code*).

* **Text Styling:** Mengatur `fontWeight` (tebal), `color` (warna), `letterSpacing` (spasi teks), dan `decoration` (efek coret pada harga asli).

* **Text Alignment:** Menggunakan `TextAlign.justify` yang dibungkus dalam `Container` agar teks rapi rata kiri-kanan.

* **Basic Layouting:** Menyusun posisi elemen menggunakan kombinasi `Column`, `Center`, dan `SizedBox`.
